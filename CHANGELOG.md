# Журнал версий

Версии по SemVer. До 1.0 вторая цифра растёт при новом этапе пайплайна или смене устройства проекта, третья — при правках. Номер версии — в `system/damp/__init__.py`.

## 0.8.1 — 2026-11-15

- **Rerun по ходу счёта**: часть прохода уровня (окна, коды, карта, детекторы, срабатывания, детали, точность) рисуется, как только готова (`LadderObserver.part`, `CycleStep.run(watch=…)`). Внутри долгих шагов — кадры раз в `RERUN_LIVE_INTERVAL` = 0.5 с: карта раскладывается на глазах, растут столбцы качества Ē (§5.8), слои детекторов заполняются один за другим (`LOGGER.watch` / `LOGGER.progress`). Прогон без кеша с показом и без — 145.2 с оба; результат тот же цифра в цифру.
- **Какой этап идёт — в сводке прогона** (вкладка «Обзор»): «▶ Идёт этап 3. Раскладка · уровень 2», таблица этапов уровня (✓ готово, ▶ идёт, ждёт) и готовые уровни с числами. Вкладка идущего этапа открывается сама (`RERUN_FOLLOW_STAGE`): окну уходит та же раскладка панелей с другой открытой вкладкой (`rr.send_blueprint`), не чаще раза в `RERUN_LIVE_INTERVAL`; в конце — «Обзор».
- **Вся работа видна в Rerun**: тесты идут с окном (`RERUN=on`; модуль тестов больше не глушит журнал, сторож `LoggerNotMutedTest`); после цикла окно само возвращается к «ходу раскладки», графики там — вся история по времени; прогон для скриншотов README тоже идёт в окно, снимки — одним окном без экрана, вкладки переключаются по очереди.
- **Путь одной пятёрки**: все её окна на вкладке этапа 2, её окно-пример на карте памяти (белое кольцо), ответ проверочной пятёрки в итоге этапа 7; в таблицах «Что видно» — строка «Итого».

## 0.8.0 — 2026-11-15

- **Пустых ячеек раскладки 15 %, как в статье (§7.1.6)**: `LAYOUT_EMPTY_RATIO` 0.5 → 0.15. Замер на 100/500 цифрах, две пары зёрен: голосование 64.0 % и 65.2 % против 65.2 % и 60.4 % — в пределах шума. Рисунки и числа README пересняты; все тесты проходят.
- **Rerun — «живой README»**: прогон цикла открывает вкладки Обзор и этапы 1–7 (`system/damp/figures/rerun_cycle.py`); шкала `cycle` — уровень; пример — цифра 5 и цифры 0–9; у видов в заголовке названы оси. Вкладки заполняются и при повторе из кеша. Тест `tests/test_rerun_cycle.py`.
- **Запись прогона** в `logs/rerun/*.rrd` (последние 10); `DAMP_RERUN_VIEWER=off` — без окна. Скриншоты вкладок для README: `python client/run.py figures --rerun` (Rerun без окна на экране).
- **Rerun 0.25 → 0.43.2**: активная шкала задаётся раскладкой панелей, снимки без окна; поля журнала в Rerun — с постоянным типом (без предупреждений).
- **Журнал**: поле `cycle` (номер уровня) в `logs/damp.jsonl`, отметки `ladder.cycle.begin` / `ladder.cycle.end`, время шагов прохода.
- **Окно внимания по-английски — keyhole** («замочная скважина», П.2): `cycle.keyholes`, `coding.keyholes`, `Keyholes`, `KeyholeCodes`, `KeyholeBuilder`, модули `cycle/keyholes.py`, `encoding/keyhole.py`, `encoding/keyhole_code.py`, пути Rerun `/keyhole/`. Записи кеша прежних шагов `cycle.windows`, `coding.windows` удалены.
- **AGENTS.md**: правило 9 — API, его документация и журнал всегда актуальны.

## 0.7.0 — 2026-11-15

- **Кеш шагов** (`system/damp/cache.py`): каждый шаг — запись сама по себе, ключ — содержимое входа, настройки, которые читает код шага, текст кода и окружение. Штрихи — по картинкам; окна, коды окон, карта, детекторы, детали, отклики, рисунки карт — по уровням. Из кеша — то же, что заново, бит в бит (тесты `tests/test_cache.py`, `ladder --verify-cache`). Повтор прогона README: 131 с → 19 с, результат тот же цифра в цифру.
- **Команды** `python client/run.py cache` (сводка, `--clear`) и `docs`; в API — `Damp().cache`.
- **Документация API**: docstring'и всего `damp_api`, HTML-справка `python client/apidocs.py` (pdoc) в `docs/api/`.
- **Настройки** раздела `[cache]`: `CACHE_ENABLED`, `CACHE_DIR`, `CACHE_MAX_BYTES` (20 ГБ), `CACHE_VERIFY_SHARE`.

## 0.6.0 — 2026-11-14

- **Цикл уровней по статье и продолжению** (этап 6): окно внимания на каждом элементе (П.2), код окна «что и где» (П.4–П.7), рост окна, остановка по охвату цифры. На 100 обучающих и 500 проверочных цифрах — три уровня, голосование верхних деталей 65.2 %.
- **Два слоя**: клиентский `client/` (настройки `config.toml` по значимости, команды `run.py`) и системный `system/damp/` (пакеты по этапам).
- **Фреймворк `client/damp_api`** для программиста: `Damp()` с полем на каждый этап пайплайна (`stimuli`, `coding`, `layout`, `detectors`, `embeddings`, `cycle`, `recognition`, `figures`). У каждого этапа — кубики для своей сборки цикла (`digits → sticks → keyholes → коды окон → memory → detectors → fire → details → vote`) и готовые прогоны. Свои настройки — `Damp(changes=…)`. Команды `run.py` переведены на него; в `system/damp` ходит только мост `damp_api/_system.py` (тест `tests/test_client_api.py`).
- **Цикл разрезан по этапам**: цифры (`stimuli/digits.py`), элементы уровня (`encoding/elements.py`), код окна (`encoding/keyhole_code.py`), окна внимания (`cycle/keyholes.py`), память уровня (`layout/level_memory.py`), детекторы (`activation/level_detectors.py`), детали (`activation/details.py`), узнавание (`decode/level_recognition.py`), проход уровня (`cycle/step.py`). Результат прежний цифра в цифру.
- **Журнал** JSON Lines с ротацией: `logs/damp.jsonl`.
- **Рисунки README** одной командой: `python client/run.py figures`.
- **Удалено старое**: опыты second, second-points, window, sticks, white-circle и способ кодирования окна «views».
