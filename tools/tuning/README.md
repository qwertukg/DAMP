# Стенд подбора

**С 2026-11-21 стенд живёт в репозитории: `tools/tuning/stand/`** — `tune_pair.ps1`, `tune_cycle.py`, опора `base.json`,
журнал всех прогонов `tune2_log.jsonl`, рисунок «X» `x_image.b64`; рабочие файлы пар и журналы прогонщика — там же, вне git.
Пути не зашиты (Python — `DAMP_PYTHON` из `.env`). Запуск всей упряжи — `pwsh tools/start.ps1`, описание —
[docs/HARNESS.md](../../docs/HARNESS.md). Ниже — прежние инструменты сессий v2 (`run_one.ps1`, `queue.sh`, `wait*.sh` и др.):
в них ещё зашиты пути временной папки, прогонщик доски их не использует.

Копия рабочих скриптов стенда подбора на 250 цифрах (прогоны 448–573 и план v2 с 574). Стенд работает из своей папки:
скопировать сюда или во временную папку скрипты, `tune2_log.jsonl` и `x_image.b64`; журналы и правки прогонов пишутся
рядом со скриптами. В `tune_pair.ps1` и `runs_table.py` — путь к рабочей копии репозитория.

**План v2 (с прогона 574).** Опора — `client/config.toml` (там вариант 561), `base.json` пуст. Точка оси — пара зёрен:
`run_pair.ps1 -First N -Label "…" -Changes '{…}'` (N — зерно 0, N + 1 — зерно 2); `summary.py 250 574` — сводка
по точкам: М1 / М2 верха, честная (страж), гладкость, дыры и ретинотопия уровня 0 (М7), нити (М3), разрешение кода (М6). Журнал стенда — `docs/runs-stand.jsonl`, таблица для
анализа — `docs/runs-analysis.csv`, сводка по осям — `docs/TUNING.md`.

- `tune_cycle.py` — один прогон: обученный цикл с правками → мерки по уровням (честная сходимость, пятна, одиночки),
  уровень 0 (доля места, гладкость пинвилов, дыры, ретинотопия), детекторы по слоям; лист карт `data/maps/tune2-N.png`.
- `run_one.ps1` — прогон N на 250 цифрах: `base.json` (опора 506) + правки JSON, скрыто. `queue.sh` — очередь прогонов.
- `wait_summary.sh`, `status.sh`, `summary.py` — ожидание, статус, сводная таблица серии.
- `runs_table.py --from 448` — пересборка `docs/RUNS.md`, `docs/runs.jsonl`, `docs/runs-analysis.csv`, `docs/runs-stand.jsonl`.
- Рисунки: `sigma_levels.py` (σ по шагам с отрезками «лидеры / плато / хвост»), `gauss_steps.py` (σ гауссова ядра),
  `compare_width.py` (ширина колокола), `retinotopy.py` (уровень 0 как ретинотопическая карта), `island.py` (островок
  уровня 0), `plateau.py` (кривые уровней по всем окнам), `detector_probe.py` (детекторы и кластеры по слоям),
  `sigma_simple.py` (схема σ), `runs_duration.py` (длительность прогонов).
