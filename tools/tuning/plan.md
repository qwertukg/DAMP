# План подбора v4 (2026-11-21, задача автора #88)

Цель прежняя: каждый класс на верхней карте — одно целое пятно. Мерка — М1u (среднее по 10 цифрам доли точек цифры в главном пятне, по 3 раскладкам верха), слабые цифры 2, 4, 5, стражи — честная и читатель.

**Прогонщик следит за этой таблицей** (`plan_sync` в `board_runner.py`): каждая новая строка с новым номером `v4.N` → карточка в «Очереди». Настройки — JSON без `|`: есть — карточка с готовым прогоном; `код` — нужна правка кода (делает Claude, без Claude — GLM). Карточка ставится один раз на номер; правка строки после этого карточку не меняет. Новую идею — новой строкой с новым номером.

## Порядок

1. Правило отбора v3.3 — чтобы видеть эффекты +0.02…0.03.
2. Только настройки, по одной: плотность 0.07, ядро верха 8, горячий отжиг верха, окна ур. 2, детекторы крупнее, σ 13, код окна реже, торможение, мягкая активация.
3. Код: топографические биты детекторов (лечит «стенки»), центрированное сходство на верху (условие для дальних сил), наклон места, рост λ, проход «лучший ответ».
4. Сочетания — только по шагам: принятое → в опору → следующее поверх.
