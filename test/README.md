# UI для нарисованной цифры

Запуск из корня проекта:

```powershell
python test/digit_ui.py
```

По умолчанию интерфейс выполняет команду:

```powershell
python main.py predict --count 60000 --image test/digit.png
```

Нарисуйте белую цифру мышкой на чёрном холсте и нажмите **«Распознать»**.
Поле `count` можно изменить прямо в окне или при запуске:

```powershell
python test/digit_ui.py --count 20000
```

UI принудительно запускает распознавание с `RERUN=off`, поэтому окно Rerun не
открывается даже при установленной системной переменной `RERUN=on`.
