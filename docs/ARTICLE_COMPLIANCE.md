# Соответствие реализации статье DAMP

Этот файл фиксирует проверяемые инварианты реализации, а не объявляет статью
спецификацией всех параметров MNIST.

Репозиторий целиком рассматривается как прикладная реализация статьи.
`pinwheel_test.py` служит обязательной быстрой интеграционной проверкой Encoder
и Layout перед длительным запуском MNIST и сохраняет проверяемый результат в
`pinwheel_test.png`.

| Раздел статьи | Реализация | Инвариант |
|---|---|---|
| §2, §2.2.4 | `BitArray`, `Layout`, `ActivationMap` | Разреженные бинарные коды; cosine или Jaccard |
| §4.1–4.6 | `Encoder`, `JointEncoder` | Перекрывающиеся широкие детекторы, случайные выходные биты, циклические координаты |
| §5.2–5.6 | `Layout` | Случайные пары, минимизация long-energy, максимизация short-energy |
| §5.7–5.8 | `Layout.average_local_energy` | Энергия точки вычисляется как сумма `sim_lambda / d` и нормируется по максимуму |
| §5.9–5.12 | `Layout` | Ранний cutoff, выбор по энергии, subset, similarity cache, параллельные CPU/GPU пути |
| §5.13.2.4 | `Layout.replace_codes` | Замена разрешения кодов без изменения установившихся позиций |
| §3.2, §5.14 | `EncoderCodeColorizer`, `Layout.colors_rgb` | RGB — сумма псевдоцветов единичных битов; доменная визуализация может выбирать компоненту кода |
| §6.1 | `ActivationMap` | `A_lambda(S)` использует максимум пороговой схожести по стимулам |
| §6.3–6.4.5 | `DetectorHierarchyBuilder` | Стохастические центры, кластер, взвешенный центр, максимум fill factor, замена перекрытий, случайный one-bit код |
| §6.5, §7.1.12 | `ActivationEngine` | Отношение энергии без clipping; динамический порог по активации; лимит насыщения |

`pinwheel_test.py` использует одну глобальную поверхность `(x, y, angle)` с
девятью коническими областями из §4.4.2/§5.13.2, по 360 углов в каждой. Номер
области не кодируется отдельными категориальными битами. Широкий совместный
код `(x, y)` объединяется с замкнутым кодом осевой ориентации. Каждая локальная
область является коническим кольцом из 360 точек: пространственный полярный
угол равен `2a`, а код осевой ориентации имеет период 180°. Количество слоёв,
перекрытия и число итераций остаются экспериментальными параметрами: статья
требует подбирать их по топологии и разрешению, но не задаёт универсальных
чисел. `AlternatingPinwheelTopology` — прикладное расширение входной предметной
топологии, которого нет в статье: оно до Encoder чередует хиральность осевой
ориентации и фазу 90° девяти пинвилов. DAMP Layout, его энергии и выходные координаты при этом
не модифицируются.
