# Подбор параметров: что подобрано и что осталось

Сводка по осям подбора. Таблицу ведём накопительно: новая ось — новая строка, подобранная ось переезжает из второй
таблицы в первую. Данные по каждому прогону — в [runs-analysis.csv](runs-analysis.csv) (строка на прогон: все параметры
и все мерки), таблица прогонов — в [RUNS.md](RUNS.md).

**Как мерено.** Стенд подбора, 250 обучающих цифр MNIST (окна уровней 2–3 — сначала на 100 цифрах). Сходимость —
честная сходимость верхней карты (доля соседних точек одной цифры среди пар с разных картинок). Влияние — разница между
лучшим и худшим из опробованных значений; шум по зерну — около ±0.01–0.02. Тег — как в `client/config.toml`.
