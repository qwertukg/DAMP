# Упряжь подбора: доска, прогонщик, роутер, GLM

Как устроен автоматический подбор параметров DAMP и как с ним работать агенту (Claude, GLM) и человеку. Правила проекта — в [AGENTS.md](../AGENTS.md), направление подбора — в [DIRECTION.md](DIRECTION.md) и [CLUSTERS.md](CLUSTERS.md), ход — в [TUNING.md](TUNING.md).

## Части

| Часть | Где | Что делает |
|---|---|---|
| Доска «Подбор параметров DAMP» | GitHub Projects, `GITHUB_URL` в `.env` | Карточки — задачи репозитория DAMP. Описание доски и колонок — там же, на доске |
| Прогонщик | `tools/tuning/board_runner.py` | Раз в минуту: берёт карточки из Очереди, гоняет пары на стенде, пишет итоги, двигает по колонкам, растит дерево |
| Стенд | `tools/tuning/stand/` | `tune_pair.ps1` → `tune_cycle.py`: один прогон = цикл на 250 цифрах + мерки. Журнал всех прогонов — `tune2_log.jsonl`, опора — `base.json` |
| Роутер | `tools/glm/router.py` | Раз в минуту: комментарии и задачи автора → Claude, а если его нет — агенту GLM |
| Агент GLM | `tools/glm/agent.py` | GLM 5.3 на сервере автора через SSH-туннель; помощник Claude и замена Claude, когда его нет |
| Опора | `tools/tuning/stand/base.json`, `tools/tuning/base_runs.json` | Принятые правки поверх `client/config.toml` и номера опорных прогонов по 12 зёрнам |
| Дерево | `tools/tuning/board_tree.json` | Узлы правок: родитель, прогоны, итог; рисуется в конце каждой карточки |
| Запуск | `pwsh tools/start.ps1` | Проверка `.env`, Python, доски, GLM; запуск прогонщика и роутера |

## Флоу доски

Колонки: **Todo → Очередь → Прогон → Анализ → Хорошие / Плохие**.

- **Todo** — кухня автора. Прогонщик и роутер её не трогают: ни заголовков, ни ответов. Сюда же прогонщик кладёт карточки с меткой «ждёт слова автора».
- **Очередь** — работа. Автор сам ставит сюда свои задачи. Берётся всегда сверху. Порядок колонки по умолчанию: приоритет 🔥 → ⬆️ → ➡️ → ⬇️, внутри — новые выше. В остальных колонках новые сверху.
- **Прогон** — идёт пара зёрен. **Анализ** — итог записан, правка ждёт решения по всем своим зёрнам или следующего этапа.
- **Хорошие** — успех: правка уходит в опору, от узла растёт «дальше» тем же шагом. **Плохие** — неудача: от опоры «полшага» или «обратно», только при |Δ| ≥ 0.03 на 4+ зёрнах и не в уже проверенное значение.
- Метки: «ждёт слова автора» — карточку никто не берёт; «пауза» — пара гасится, снятие — заново с этапа 1.
- Комментарии автора ловятся во всех колонках, кроме Todo. Ответ — в той же задаче.
- Закрывать задачи нельзя: встроенная автоматизация доски «Item closed» переносит закрытую задачу в «Плохие». «Плохие» доска закрывает сама.

## Карточка

- Заголовок: `⬇️ ❌ [было] → [стало] что проверяем`. Эмодзи приоритета — всегда и первым; ✅ в Хороших, ❌ в Плохих.
- Тело над картами: **Что пробуем** (коротко), **Подробно**, **Было**, **Стало**. Ниже — итоги прогона, карты «было / стало», свёрнутое «Служебное», в конце — дерево прогонов.
- Служебное: блок `карточка` (шапка), блок `прогон` (`{"changes": {...}, "label": ..., "priority": 0–3}`; ещё `"base": true, "seeds": [...]` — опора; `"check": true` — проверка без принятия), блок `состояние` (прогонщик).
- Одна карточка — один прогон (одно зерно). Правка — группа карточек-зёрен с общим `variant`; решение — по правке целиком.
- Обозначение прогона: `v3.720`, подряд `v3.720–723` (версия плана, номер). Поля «Версия» и «Прогоны» на плитке.
- Свои комментарии всегда начинать с `🤖 Claude:` или `🤖 GLM:`: прогонщик и роутер считают такие своими (токен у всех один).

## Правило отбора v3.2

Мерка — **М1u**: доля точек цифры в её главном пятне на верхней карте, среднее по 10 цифрам и 3 раскладкам верха. Δ — к **среднему опоры по 12 зёрнам**. Этапы: зёрна 1/3 → 0/2 → 4/5. Пороги М1u: 0 / +0.02 / +0.035; принять можно только по 6 зёрнам. Ещё пути: слабые цифры 2, 4, 5 (+0.03 / +0.05 / +0.06 при М1u не хуже −0.01), пятна и монопятна на каждом зерне. Стражи — честная сходимость и читатель: только сообщать.

## Работа агента

1. **Сначала статья**: `docs/DAMP_extracted.txt`, `docs/DAMP_continuation.md` (тот же вес), при неясности — `docs/DAMP.pdf`. Цитата с § — рядом с решением; близость к статье `[NN %]`.
2. **Очередь разбирать по умолчанию**, сверху вниз. Правка кода — новой настройкой в `client/config.toml` с тегом `[КАНОН] / [РАСШИРЕНИЕ] / [НЕ КАНОН]`, **по умолчанию выключена**; проверка на CPU, что по умолчанию ответ бит в бит прежний; затем блок «прогон» в карточке — прогонщик возьмёт сам.
3. **Ничего не коммитить и не пушить** без слова автора. Прогоны вручную мимо прогонщика не запускать.
4. **Ресурсы**: на стенде одна пара; свободно ≥ 6 ГБ ОЗУ и ≥ 1.5 ГБ видеопамяти; Rerun выключен.
5. Отчёт — коротко, по-русски, таблицей с «Итого»; к прогону — карты.

## GLM

- Модель `glm-5.3-flash-nvidia` (vLLM) на сервере автора, слушает 127.0.0.1:8893 там; агент поднимает SSH-туннель на 127.0.0.1:18893 (`GML_SSH_HOST`, `PASS_SSH_PASS` из `.env`, пароль — через `tools/glm/askpass.sh`). 2 потока — 2 слота-замка.
- `python tools/glm/agent.py ask "…"` — только чтение репозитория; `--board` — ещё доска (комментарий, приоритет, перенос Todo / Очередь / Хорошие); `--full` — замена Claude: запись файлов, bash с запретами (сеть, IP, git-запись, удаление, процессы, пакеты, стенд), блок «прогон», новые карточки, помощник во втором потоке. Это ограда, а не песочница.
- **Claude использует GLM как саб-агента для простых задач** (поиск по коду, сводки, проверки доски, черновики текста), до 2 сразу, и проверяет результат. Что умеет: чтение, поиск, объяснение кода, проверки по правилам — да; правка кода с тестом — да, но медленно (5 мин) и с подсказкой «edit_file кусками».
- Роутер: Claude на месте, если `stand/claude.heartbeat` моложе 5 мин — ждёт его ответа 15 мин, потом GLM; Claude нет — сразу GLM, в полном режиме, разбирает и Очередь. Журнал шагов GLM — `%TEMP%/damp-glm-logs/`.

## Токены

- `GITHUB_TOKEN` — классический, **только `project`** (доска; без доступа к коду).
- `GITHUB_ISSUES_TOKEN` — с точными правами: только `qwertukg/DAMP`, Issues — Read and write, Contents — No access (комментарии, заголовки, тексты, создание задач). `tools/tuning/board.py` выбирает токен сам по виду запроса; `board.py scopes` — проверка.
- Карты прогонов в репозиторий не выкладываются (это запись в код); включаются отдельным репозиторием карт со своим токеном (`DAMP_MAPS_UPLOAD`).

## Новая машина

1. `git clone`, ветка подбора; Python 3.13 и venv с зависимостями DAMP (как в README).
2. `cp .env.example .env`, заполнить: два токена, адрес и пароль GLM, `DAMP_PYTHON`.
3. `pwsh tools/start.ps1` — проверит `.env`, Python, доску и токены, туннель к GLM, поднимет прогонщик и роутер. `-Status` — состояние, `-Stop` — остановить.
4. Claude в начале сессии — по [CLAUDE.md](../CLAUDE.md).
